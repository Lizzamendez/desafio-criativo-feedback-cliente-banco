# 🏦 Análise de Feedback de Clientes Bancários com IA

> Prompt estruturado desenvolvido para o **Desafio Criativo da DIO**, criado para orientar uma IA a transformar comentários soltos de clientes em insights claros, acionáveis e seguros.

---

## 📌 Sobre o projeto

Este repositório contém um prompt completo para análise de feedbacks de clientes de um banco digital — cobrindo canais como **aplicativo, Pix, cartão de crédito e atendimento por chat**.

O objetivo é apoiar equipes de experiência do cliente na priorização de melhorias, a partir de uma análise estruturada, rastreável e com controle de acesso conforme o público que vai ler o resultado.

## 🎯 O que o prompt faz

| Recurso | Descrição |
|---|---|
| 🗂️ **Classificação** | Tema, sentimento, urgência e produto citado |
| 📊 **Quantificação** | Percentual/contagem de comentários por tema |
| 🔍 **Rastreabilidade** | Cada insight aponta os comentários que o sustentam |
| ⚖️ **Neutralidade** | Nenhum canal ou produto é favorecido na análise |
| 🧩 **Tratamento de ambiguidade** | Sentimentos mistos e temas pouco claros são sinalizados |
| 🧹 **Qualidade de dados** | Lida com comentários vazios, duplicados ou incompletos |
| 🔐 **Controle de acesso** | Nível de detalhe ajustado conforme o público (gerência, equipe interna ou externo) |
| 🚫 **Privacidade** | Nunca expõe dados pessoais ou sensíveis, mesmo em exemplos |

## 🚀 Como usar

1. Copie o conteúdo do arquivo `prompt-final-feedback-bancario.md`.
2. Cole em uma IA de sua preferência (ex: Claude, ChatGPT).
3. Preencha o campo **"Público e nível de acesso da resposta"** de acordo com quem vai receber o resultado.
4. Anexe a base de feedbacks (planilha ou lista de comentários).
5. Receba um resumo executivo, uma tabela de temas e as 3 prioridades mais importantes.

## 🧠 Metodologia

O prompt foi construído em três etapas, seguindo a estrutura do Desafio Criativo:

1. **Intenção** — o que a IA deve produzir e para quem
2. **Contexto e restrições** — dados disponíveis e cuidados necessários
3. **Prompt final** — unificação de papel, tarefa, instruções, formato e restrições

Ao longo da construção, o prompt foi refinado com critérios objetivos de urgência, tratamento de dados incompletos, rastreabilidade dos insights e um mecanismo de controle de acesso por público.
